# Personal Finance Tracker

A simple personal finance tracker built with Python and Tkinter. It stores income and expense transactions locally in a JSON file.

## Run the desktop app

```bash
python finance_frontend.py
```

The app lets you add transactions, view income, expenses, and balance, and delete selected transactions.

## Run the command-line version

```bash
python finance_tracker.py
```

Your local `finance_data.json` file is ignored by Git so personal financial information is not uploaded to GitHub.
